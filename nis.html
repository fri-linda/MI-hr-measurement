Hospital system (NIS)

Receives heart rate measurements from Camera Pulse or another device as FHIR or HL7 v2 messages, checks them like a real hospital system and answers the sender.

Where is the data?

This page has no server. A measurement gets here only in a link, QR code or code that you bring yourself, and browsers never send the part of a link after # to any server. Received measurements are kept only in this browser on this device (its local storage) and Delete all data below removes them. Try it: once the page is open, turn on airplane mode. Everything keeps working.
